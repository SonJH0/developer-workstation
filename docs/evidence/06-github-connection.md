# 06-github-connection — 실제 실행 기록

원본 실행 기록에서 터미널 색상·제목·쉘 메타데이터와 제어문자를 제거한 열람용 사본입니다. 중복 출력은 유지했습니다. 출력 결과를 새로 만들어 넣지 않았습니다.

```text
$ git remote -v
origin	https://github.com/SonJH0/developer-workstation.git (fetch)
origin	https://github.com/SonJH0/developer-workstation.git (push)
$ git status
On branch main
Your branch is up to date with 'origin/main'.

nothing to commit, working tree clean
$ git log --oneline -1
095af98 feat: Docker 웹 서버와 개발 환경 실습 기록 추가

```
